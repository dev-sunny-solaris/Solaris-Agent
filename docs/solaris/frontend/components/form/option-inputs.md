# Option-input Family Router

Owner: Core

Read [Form](form.md) first when Form-owned. Choose only the needed child:

| Requirement | Guide |
|---|---|
| Searchable/reference data | [Lookup](lookup.md) — default choice |
| Explicit native/static select | [Select](select.md) |
| Boolean, radio choice, switch styling, or grouped options | [Option controls](option-controls.md) |

Lookup is the default for dropdown/reference UX. Select is not a shortcut for remote model lookup.
